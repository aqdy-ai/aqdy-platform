# User Guide

> How to use the Aqdy contract analysis platform.

## 📖 Overview
Aqdy is an AI‑powered contract risk analysis platform tailored for the Arabic‑speaking market. Users can upload contracts (PDF/DOCX), obtain clause‑by‑clause risk assessments, view bilingual explanations, and receive redline revision suggestions, all powered by large language models, a semantic RAG pipeline, and a curated legal knowledge base.

## 🛠️ Prerequisites
- **Node.js** ≥ 18 (recommended latest LTS)
- **npm** (comes with Node) or **pnpm**/**yarn** if you prefer
- **Docker & Docker Compose** (for the full stack services)
- Access to required API keys (Gemini, Pinecone, MongoDB, Stripe, Doppler, etc.) – see `.env.example`.

## 📦 Installation
1. **Clone the repository**
   ```bash
   git clone https://github.com/aqdy-ai/aqdy-platform.git
   cd aqdy-platform
   ```
2. **Create an environment file**
   ```bash
   cp .env.example .env
   # Fill in the secrets (Gemini API key, Pinecone credentials, MongoDB URI, etc.)
   ```
3. **Install dependencies**
   ```bash
   npm ci   # installs workspace packages for both backend and frontend
   ```

## 🚀 Running the Project
You can run the platform either via Docker Compose (recommended) or using the workspace dev servers.

### Option 1: Docker Compose (all services)
```bash
docker compose up --build   # starts Redis, backend, and frontend containers
```
The UI will be available at `http://localhost:5173` and the API at `http://localhost:3000`.

### Option 2: Manual Development Servers
```bash
# Frontend (Vite) – in one terminal
npm run dev --workspace=frontend -- --host 127.0.0.1

# Backend (Express) – in another terminal
npm run dev --workspace=backend
```
Both servers hot‑reload on code changes.

## 📚 Core User Flows
### 1️⃣ Creating an Account & Logging In
- Navigate to **/signup**, fill in email, password, and preferred language (Arabic/English).
- Verify your email (if configured) and log in via **/login**. A JWT token is stored in local storage for authenticated requests.

### 2️⃣ Uploading a Contract
- From the dashboard, click **Upload Contract**, choose a PDF or DOCX file, and submit.
- The platform extracts clauses, runs the AI risk classifier, and stores the analysis.

### 3️⃣ Understanding the Risk Analysis Dashboard
- After processing, the dashboard displays a **risk summary**, a **heat‑map**, and a list of **high‑risk clauses**.
- Click a clause to view a detailed bilingual explanation and suggested mitigations.

### 4️⃣ Reading Clause‑by‑Clause Risk Assessments
- Each clause card shows:
  - Risk level (Low/Medium/High)
  - Legal references from Egyptian law
  - Suggested actions for the user.

### 5️⃣ Viewing Redline Suggestions
- For contracts that need revision, open the **Redline Editor** to see autogenerated suggestions inserted directly into the document.

### 6️⃣ Providing Feedback
- Users can give a thumbs‑up/down or report an issue for any clause or redline suggestion. Feedback is sent to the backend and stored for future model fine‑tuning.

### 7️⃣ Subscription Plans & Billing
- Free tier includes up to **5 contracts per month**.
- Paid plans (monthly/annual) unlock higher limits, priority processing, and premium support. Billing is handled via Stripe.

### 8️⃣ Arabic/English Language Switching
- The UI includes a language toggle in the header. All content (UI strings, analysis results, and legal references) switches instantly between Arabic and English.
